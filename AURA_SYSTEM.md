# Aura AI: Application Functionality & Architecture

Aura is a mindful companion designed to align your daily life through AI-driven insights, ritual tracking, and personal growth gamification.

## 核心功能 (Core Functionality)

### 1. Daily Alignment (Home)
- **Morning Inspiration**: Curated "Daily Look" (outfit) and "Morning Fuel" (nutrition) suggestions tailored to the weather and user profile.
- **Smart Rituals**: Dynamic, sequential checklists generated by AI (one mission at a time).
- **Ritual Brewing**: Completing a ritual triggers the "brewing" of the next mission, ensuring focus and steady progression.
- **Advanced Resilience**: Robust error handling to process AI-generated content in various formats (JSON, raw text, markdown blocks).
- **Environmental Awareness**: Real-time reminders (e.g., SPF/UV index) based on local conditions.

### 2. Conversational Wisdom (Chat)
- **Context-Aware AI**: Aura remembers your name, goals, and history to provide deeply personalized guidance.
- **Persistent Histories**: Conversations are stored and categorized, allowing for continuous growth across sessions.
- **XP Integration**: Every meaningful interaction with Aura awards **5 XP**.

### 3. Focus & Reflections (Insights)
- **Session Management**: Start focus blocks or meditation sessions geared toward specific goals (Productivity, Zen, Heart, Nature).
- **Post-Session Brewing**: AI analyzes session metrics to "brew" custom ritual suggestions for the following day.
- **Reward Engine**: Starting a focus session awards **10 XP**.

### 5. Growth & Ascension (Profile)
- **Gamified Leveling**: A linear progression system (100 XP per level) that visually maps your growth journey.
- **Seeker Tiers**: Users progress through spiritual ranks such as:
    - *Silent Seeker* (Level 1-5)
    - *Luminous Aura* (Level 6-10)
    - *Transcendent Being* (Level 11+)
- **Identity Management**: Custom profile picture uploads and dynamic level badges in the app header.

## 技术栈 (Technical Stack)

- **Frontend**: React + Vite + TypeScript.
- **Styling**: Vanilla CSS + Tailwind CSS (as requested/used).
- **Backend**: Supabase (Auth, PostgreSQL, Storage).
- **Intelligence**: Integration with n8n workflow engine for ritual generation and vision brewing.

## Gamification Mechanics

| Action | Reward | Frequency |
| :--- | :--- | :--- |
| Ritual Completion | 15 XP | Per Ritual |
| Starting Focus Session | 10 XP | Per Session |
| AI Interaction | 5 XP | Per Response |
| Level Up | New Tier Name | Every 100 XP |
